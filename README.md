## 概要

計算モードは 2 つある。

| モード | 入力 | 出力 |
|--------|------|------|
| 順方向 (forward) | $I_{C1}, I_{C2}$、比 $V_R : V_C$ と $R_F$ | $R_1, R_2, R_3$ |
| 順方向、$V_E$ 指定 | $I_{C1}, I_{C2}$、比 $V_R : V_C : V_E$ | $R_1, R_2, R_3, R_F$ |
| 逆計算 (reverse) | $R_1, R_2, R_3, R_F$ | $I_{C1}, I_{C2}$ |

どちらのモードでも、ノード電圧、各トランジスタの動作点と動作領域、枝電流、交流解析（電圧利得・入力インピーダンス）、電圧配分 $V_R, V_C, V_E$ を表示する。計算は `js/engine.js` にまとめてあり、DOM には触れない。

## 回路と記号

| 素子 | 接続 | 備考 |
|------|------|------|
| Q1 | B = B1, C = C1, E = GND | |
| Q2 | B = C1, C = C2, E = E2 | |
| $R_1$ | $V_{CC}$ – C1 | |
| $R_2$ | $V_{CC}$ – C2 | |
| $R_3$ | E2 – GND | |
| $R_F$ | E2 – B1 | 帰還抵抗 |
| $R_{BC1}$ | B1 – C1 | 任意。$\infty$ で無し |
| $R_{BC2}$ | C1 – C2 | 任意。$\infty$ で無し |
| $RV_1$ | E2 – GND | コンデンサ結合。交流のみ |
| $RV_2$ | C2 – GND | 出力のボリュームポット。コンデンサ結合。交流のみ |
| $R_{in}$ | 信号源 – $C_{in}$ – B1 | 信号源インピーダンス（入力 `Rin`、既定 1 kΩ、0 可）。$C_{in}$ が直流を遮断するので交流のみ |
| $C_{in}$, $C_{E2}$, $C_{out}$ | 入力、$RV_1$ と直列、C2 – $RV_2$ | 結合・バイパス容量（既定 1 µF, 20 µF, 10 nF、$\infty$ で短絡）。周波数特性だけに使う |
| $C_{BC1}$, $C_{BC2}$ | B1 – C1, C1 – C2 | 任意の外付け容量（既定なし）。周波数特性だけに使う |

入力コンデンサにより B1 は直流的に外部から切り離されている。旧版にあった $R_2$ の分圧出力（$R_{2t}$, $R_{2b}$）は廃止した。逆計算は互換のため $R_{2t} + R_{2b}$ の入力も受け付け、和を $R_2$ として扱う。

直流の回路方程式は次のとおり（$V_{B1} = V_{BE1}$）。

$$
\begin{align}
\text{KCL B1:}\quad & \frac{V_{E2}-V_{B1}}{R_F} + \frac{V_{C1}-V_{B1}}{R_{BC1}} = I_{B1}\\
& V_{C1} = V_{E2} + V_{BE2}\\
\text{KCL C1:}\quad & \frac{V_{CC}-V_{C1}}{R_1} + \frac{V_{C2}-V_{C1}}{R_{BC2}} = I_{C1} + I_{B2} + \frac{V_{C1}-V_{B1}}{R_{BC1}}\\
\text{KCL C2:}\quad & \frac{V_{CC}-V_{C2}}{R_2} = I_{C2} + \frac{V_{C2}-V_{C1}}{R_{BC2}}\\
\text{KCL E2:}\quad & I_{C2} + I_{B2} = \frac{V_{E2}}{R_3} + \frac{V_{E2}-V_{B1}}{R_F}
\end{align}
$$

$R_{BC1} = R_{BC2} = \infty$ のとき、従来の回路方程式にそのまま一致する。

## トランジスタモデル

SPICE の Gummel-Poon モデルの直流部分（SPICE3 / ngspice の bjtload と同じ式）を使う。B–E 接合と B–C 接合の両方を含むので、能動領域・飽和・カットオフを同じ式で扱える。

$$c_{be} = I_S\left(e^{v_{be}/(N_F V_T)} - 1\right), \qquad c_{bc} = I_S\left(e^{v_{bc}/(N_R V_T)} - 1\right)$$

$$c_{ben} = I_{SE}\left(e^{v_{be}/(N_E V_T)} - 1\right), \qquad c_{bcn} = I_{SC}\left(e^{v_{bc}/(N_C V_T)} - 1\right)$$

$$q_1 = \frac{1}{1 - v_{bc}/V_{AF} - v_{be}/V_{AR}}, \qquad q_2 = \frac{c_{be}}{I_{KF}} + \frac{c_{bc}}{I_{KR}}, \qquad q_b = \frac{q_1}{2}\left(1 + \sqrt{1 + 4 q_2}\right)$$

$$I_C = \frac{c_{be} - c_{bc}}{q_b} - \frac{c_{bc}}{B_R} - c_{bcn}, \qquad I_B = \frac{c_{be}}{B_F} + c_{ben} + \frac{c_{bc}}{B_R} + c_{bcn}$$

使うパラメータは IS, BF, NF, ISE, NE, BR, NR, ISC, NC, VAF, VAR, IKF, IKR で、省略時は SPICE の既定値（BR = 1, NR = 1, ISC = 0, NC = 2, VAF・VAR・IKF・IKR は $\infty$、0 も $\infty$ と見なす）を使う。RB, RE, RC は交流解析にだけ使う。入力の `gmin`（既定 0）を与えると、SPICE と同じく $g_{min} v_{be}$, $g_{min} v_{bc}$ を $c_{ben}$, $c_{bcn}$ に足す。LTspice の既定は $10^{-12}$ S だが、Fuzz Face の電流域では影響は $10^{-6}$ 以下である。

**動作領域の判定**

- カットオフ: $I_C < 1$ nA または $I_B \le 0$
- 飽和: $v_{bc} > 0$ で、B–C 接合のダイオード電流 $c_{bc}/B_R + c_{bcn}$ が $I_B$ の 0.1 % を超える（$g_\mu \gtrsim 10^{-3} g_\pi$。利得が急落し始める $V_{CE} \approx 0.2$ V 付近から飽和と表示する）
- 能動: それ以外

B–C 接合の電流と、その小信号コンダクタンス $g_\mu = \partial I_B/\partial v_{bc}$ は同じ指数で増える。上の条件はおおむね $g_\mu > 0.01\, g_\pi$ に相当し、B–C 接合がトランジスタ内部のコレクタ・ベース間帰還抵抗として効き始める点を境にしている。$I_C/I_B$ がまだ $B_F$ に近い浅い飽和もここで飽和と判定する。既定モデルでは、$V_{CE2} = 0.165$ V（$V_{BC2} = +0.45$ V）は飽和、$V_{CE2} = 0.22$ V（$V_{BC2} = +0.39$ V）は能動になる。

**表示する小信号量**

動作点でのモデルの偏微分から求める。

| 量 | 定義 |
|----|------|
| $h_{fe}$ | $I_C/I_B$（直流電流増幅率） |
| $\beta_{ac}$ | $g_m/g_\pi$ |
| $g_m$ | $\partial I_C/\partial v_{be}$ |
| $r_o$ | $-1/(\partial I_C/\partial v_{bc})$。0 なら $\infty$ |
| $r_{ie}$ | $R_B + 1/g_\pi$, $g_\pi = \partial I_B/\partial v_{be}$ |

旧版の $r_{ie} = R_B + h_{fe} N_F V_T/I_C + (1 + h_{fe}) R_E$ は使わない。$r_{ie}$ は $R_E$ を含まない入力抵抗になった。

**旧版との違い**

- 旧版は $V_{BE} = V_T \ln(I_C/I_S)$ としており、$N_F$ を含めていなかった。既定の 2SC8888-W（$N_F = 1.002$）では $V_{BE}$ が約 1 mV 変わる。
- 旧版には B–C 接合がなく、飽和すると $V_{C2} < 0$ のような物理的にありえない解を返していた。
- 能動領域では B–C 接合の項は無視できる。$V_{AF} = I_{KF} = \infty$ のとき、新旧の直流解は相対 $10^{-6}$ 以内で一致する（テスト 3b）。$V_{AF} = 125.5$ V, $I_{KF} = 385$ mA を含めると、$R_3 = 1.1\ \text{k}\Omega$ の例で $I_{C2}$ が 0.4 % 変わる。
- $I_S$ の大きいゲルマニウム系モデルでは $-I_S/B_R$ などの漏れ項が $I_B$ と同程度になり、旧版とは一致しない。SPICE と同じ振る舞いである。

## 順方向計算

$I_{C1}, I_{C2}$ を与え、$R_1, R_2, R_3$ を決める。$V_{BE}$ は $V_{BC}$ にわずかに依存する（アーリー効果と B–C 接合の電流）。そこで $V_{BC1}, V_{BC2}$ について固定点反復を行う。各反復では $I_C(v_{be}, v_{bc})$ が目標値になる $v_{be}$ を Brent 法で求め、残りを下の閉じた式で計算する。能動領域では数回で $10^{-13}$ V まで収束する。指定した電流と比で深く飽和する場合は収束せず、エラーになる。

電圧配分の指定は 2 通りある。

### $V_R : V_C$ を指定する場合（$R_F$ は入力）

$R_2$ の電圧降下 $V_R = V_{CC} - V_{C2}$ と Q2 の $V_C = V_{CE2} = V_{C2} - V_{E2}$ の比を $V_R : V_C = v_r : v_c$ とする。$V_{E2}$ は $I_{C1}$ と $R_F$ で決まる。

**Step 1: $V_{E2}$ と $R_3$**

KCL B1 は $V_{E2}$ について線形である。

$$V_{E2} = \frac{I_{B1} + V_{B1}/R_F + (V_{B1} - V_{BE2})/R_{BC1}}{1/R_F + 1/R_{BC1}}$$

$$I_F = \frac{V_{E2} - V_{B1}}{R_F}, \qquad R_3 = \frac{V_{E2}}{I_{C2} + I_{B2} - I_F}$$

$R_{BC1} = \infty$ なら $V_{E2} = V_{BE1} + I_{B1} R_F$ となる。

**Step 2: $V_{C2}$ と $R_2$**

$$V_{C2} = V_{E2} + \frac{v_c}{v_r + v_c}\,(V_{CC} - V_{E2})$$

$$I_{BC2} = \frac{V_{C2} - V_{C1}}{R_{BC2}}, \qquad R_2 = \frac{V_{CC} - V_{C2}}{I_{C2} + I_{BC2}}$$

**Step 3: $R_1$**

$$I_{BC1} = \frac{V_{C1} - V_{B1}}{R_{BC1}}, \qquad R_1 = \frac{V_{CC} - V_{C1}}{I_{C1} + I_{B2} + I_{BC1} - I_{BC2}}$$

### $V_R : V_C : V_E$ を指定する場合（$R_F$ は出力）

石橋幸男『アナログ電子回路演習』pp.84–85 の式 (4.14) は、2 段直結増幅回路の電源電圧を $V_R : V_C : V_E = 1+\varepsilon : 1 : 0.2\text{〜}1$ に配分する。[Zenn の記事](https://zenn.dev/bj_9/articles/c817af3419b009)では、$V_E$ が Q1 のバイアス（$V_{E2} = V_{BE1} + I_F R_F$）で決まってしまうため、この項を落として $V_R : V_C$ だけを使った。ここでは $R_F$ を未知数に回すことで $V_E$ の指定を取り戻す。

入力 `veRatio` $= v_e > 0$ を与えると、$S = v_r + v_c + v_e$ として

$$V_{E2} = \frac{v_e}{S} V_{CC}, \qquad V_{C2} = V_{E2} + \frac{v_c}{S} V_{CC}, \qquad V_R = \frac{v_r}{S} V_{CC}$$

とする。$V_{B1} = V_{BE1}$, $V_{C1} = V_{E2} + V_{BE2}$ から $I_{BC1}$ が決まり、KCL B1 を $R_F$ について解く。

$$R_F = \frac{V_{E2} - V_{B1}}{I_{B1} - I_{BC1}}$$

$R_3, R_2, R_1$ は上の Step 1〜3 と同じ式で求める。$V_{E2} \le V_{BE1}$ なら「V_E が小さすぎる」、$I_{B1} \le I_{BC1}$ なら「R_BC1 の電流が I_B1 を超える」としてエラーにする。`veRatio` が未指定・0・NaN のときは従来どおり $R_F$ を入力として扱う。結果の `Rf` は常に返し、`RfComputed` で出力かどうかを示す。

いずれの場合も、抵抗が 0 以下か有限でなくなるときは理由を添えてエラーにする（例: 「R3 が負になる: I_C2 が小さすぎる」）。

## 逆計算

$R_1, R_2, R_3$ から動作点を求める。未知数は節点電圧 $x = (V_{B1}, V_{C1}, V_{E2}, V_{C2})$ で、4 つの KCL を Newton-Raphson 法で解く。接合電圧は $v_{be1} = V_{B1}$, $v_{bc1} = V_{B1} - V_{C1}$, $v_{be2} = V_{C1} - V_{E2}$, $v_{bc2} = V_{C1} - V_{C2}$ である。ヤコビアンはモデルの解析的な偏微分から組む。

**接合電圧の制限 (pnjlim)**

SPICE と同じく、各反復で接合電圧の増分を制限する。$v_{new} > v_{crit}$ かつ $|v_{new} - v_{old}| > 2 n V_T$ のとき

$$v_{new} \leftarrow v_{old} + n V_T \ln\!\left(1 + \frac{v_{new} - v_{old}}{n V_T}\right), \qquad v_{crit} = n V_T \ln\frac{n V_T}{\sqrt{2}\, I_S}$$

とし、制限後の電圧でデバイスを評価して線形化する。指数関数は $e^{80}$ より上を線形に延長し、オーバーフローを防ぐ。収束判定は「制限が掛からず、更新量が $10^{-10}(1 + \max|x|)$ V 以下」とした。

**初期値と収束補助**

1. 旧版の順方向能動モデルで解いた動作点を初期値にする。この解は括弧付けの入れ子求根で必ず求まる。内側では KCL E2 が $I_{C2}$ について単調なので根が 1 つに決まり、外側では $I_{C1}$ の対数格子を走査して KCL C1 の符号変化を Brent 法で詰める。飽和で $V_{C2} < V_{E2}$ となる場合は、$V_{C2} = V_{E2} + 0.05$ V に補正してから使う。
2. ここからの Newton 法が収束しなければ、全節点に GND へのコンダクタンス $g_s$ を入れ、$10^{-2}$ S から 0 まで段階的に下げる (gmin stepping)。
3. 独立な出発点として、電源電圧を 0 V から段階的に上げる source stepping も毎回実行する。

1–2 と 3 の解が $10^{-6}$ V 以上離れていれば別の根として数え、`solver.roots` に返す。根が複数あれば警告を出し、警告の少ない解を表示する。$R_F$, $R_{BC1}$, $R_{BC2}$ はどれも負帰還で、通常の範囲では根は常に 1 つだった。極端なパラメータの乱数試験 5000 件では 1 件だけ 2 つの根が見つかった。どの方法でも収束しなければエラーにする。

**結果の検査**

4 つの KCL 残差を厳密なモデル（線形化なし）で計算し、最大値を `solver.maxResidual`（A）として返す。電流スケールに対して相対 $10^{-6}$ と絶対 $10^{-15}$ A の和を超えたらエラー、相対 $10^{-9}$ と絶対 $10^{-17}$ A の和を超えたら警告とする。絶対値の下限は、$V_{CC} = 50$ mV のように電流が pA 未満になる回路を誤って非収束と判定しないために入れた。通常の残差は $10^{-18}$ A 程度である。

**既定回路の例**（2SC8888-W の全 DC パラメータ、$V_{CC} = 9$ V, $R_1 = 33\ \text{k}\Omega$, $R_2 = 8.2\ \text{k}\Omega$, $R_F = 100\ \text{k}\Omega$, $V_T = 25.85$ mV）

| $R_3$ | $I_{C1}$ | $I_{C2}$ | $V_{C1}$ | $V_{E2}$ | $V_{C2}$ | Q1 / Q2 |
|------|------|------|------|------|------|------|
| 390 Ω | 4.60 µA | 1.036 mA | 1.156 V | 0.495 V | 0.505 V | 能動 / 飽和 |
| 1.1 kΩ | 231.8 µA | 0.6076 mA | 1.289 V | 0.670 V | 4.017 V | 能動 / 能動 |

$R_3 = 390\ \Omega$ では Q2 が深く飽和し、$V_{CE2} = 10$ mV になる。旧版はこの回路で $V_{C2} = -4.96$ V という解を返していた。

## 交流解析

中域の小信号解析を節点解析（ガウスの消去法）で行う。結合コンデンサは短絡、接合容量は無視する。

各トランジスタは、動作点でのモデルの偏微分による 2 端子対の y パラメータで表す。

$$i_b = g_\pi v_{be} + g_\mu v_{bc}, \qquad i_c = g_m v_{be} + g_x v_{bc}$$

$$g_\pi = \frac{\partial I_B}{\partial v_{be}},\quad g_\mu = \frac{\partial I_B}{\partial v_{bc}},\quad g_m = \frac{\partial I_C}{\partial v_{be}},\quad g_x = \frac{\partial I_C}{\partial v_{bc}}$$

出力抵抗 $r_o = -1/g_x$ と B–C 接合のコンダクタンス $g_\mu$ を含むので、浅い飽和でも正しい値が出る。RB, RE, RC は内部節点を設けて直列に入れる（入力 `acOhmic`、既定 true）。直流解には RB, RE, RC を入れていないが、交流で入れた方が LTspice との差が小さかった（下表）。

| 素子 | 接続 |
|------|------|
| Q1 | B1, C1, GND |
| Q2 | C1, C2, E2 |
| $R_1$ | C1 – GND |
| $R_2 \parallel RV_2$ | C2 – GND（$V_{CC}$ は交流的に GND） |
| $R_E = R_3 \parallel RV_1$ | E2 – GND |
| $R_F$ | E2 – B1 |
| $R_{BC1}$ / $R_{BC2}$ | B1 – C1 / C1 – C2 |

B1 に $v_{in} = 1$ V の理想電圧源をつなぎ、残りの節点電圧を解く。

$$A_v = \frac{v_{C2}}{v_{in}}, \qquad Z_{in} = \frac{v_{in}}{i_{in}}$$

$i_{in}$ は電圧源から B1 に流れ込む電流である。Q1, Q2 ともに反転増幅なので古典回路では $A_v > 0$ になる。`ac.Av` は大きさ、`ac.AvSigned` は符号付きの値、`ac.AvdB` は $20\log_{10}|A_v|$ である。表示用に $R_E = R_3 \parallel RV_1$ と $R_C = R_2 \parallel RV_2$ も返す。

**信号源インピーダンス $R_{in}$**

信号源 $v_s$ は $R_{in}$ と $C_{in}$（中域では短絡）を通して B1 につながる。$Z_{in}$ は B1 から見た線形回路の入力インピーダンスなので、信号源から見た利得は分圧で厳密に表せる。

$$A_{vS} = \frac{v_{C2}}{v_s} = A_v \frac{Z_{in}}{R_{in} + Z_{in}}$$

`ac.AvS`, `ac.AvSSigned`, `ac.AvSdB` として返す。`ac.Av` は B1 基準のまま変えない。テストでは $v_s = 1$ V を $R_{in}$ の奥に置いた節点解析と比べ、相対 $10^{-9}$ 以内で一致することを確かめている。直流解は $R_{in}$ の影響を受けない。

いずれかのトランジスタが飽和かカットオフのときは `ac.valid = false` とし、警告を出す。A_v と Z_in はその動作点での小信号値として計算し、LTspice の .ac と一致する。UI は値をそのまま表示し、region 行と警告で動作領域を示す。

## 周波数特性

`FFEngine.acSweep(inputs, opts)`（または `acSweep(result, inputs, opts)`）は、動作点での小信号モデルに容量を加えた複素節点解析で、$f$ = 10 Hz〜1 MHz（既定 200 点、対数間隔）の周波数特性を返す。

**回路**

信号源 $v_s$ – $R_{in}$ – $C_{in}$ – B1、E2 – $C_{E2}$ – $RV_1$ – GND、C2 – $C_{out}$ – $RV_2$ – GND とし、出力は $RV_2$ の上端（ボリューム最大）にとる。$C_{BC1}$, $C_{BC2}$ は外部節点 B1–C1、C1–C2 の間に入れる。

**トランジスタの容量**（SPICE と同じ式、XCJC = 1）

- 空乏層容量 $C_{je}(v_{be})$, $C_{jc}(v_{bc})$: $C_{j0}(1 - v/V_J)^{-M}$。$v > F_C V_J$ では SPICE と同じ直線近似にする。
- 拡散容量: $T_F\, \partial(c_{be}/q_b)/\partial v_{be}$（$\approx T_F g_m$）と $T_R\, \partial c_{bc}/\partial v_{bc}$。$T_R$ の項は能動領域ではほぼ 0 で、飽和時にだけ効く。
- $C_{be} = C_{je} + $ 順方向拡散容量を内部節点 b'–e' 間に、$C_{bc} = C_{jc} + $ 逆方向拡散容量を b'–c' 間に置く。RB, RE, RC は直列抵抗として外側に入る。
- XTF, VTF, ITF（TF の電流依存）は入れない。既定モデルでは $(I_C/I_{TF})^2 X_{TF} \approx 10^{-5}$ で効かない。PTF（過剰位相）、CJS（基板容量）も入れない。

**出力**

`AvS`（大きさ・dB・位相）、`Zin`（$R_{in}$ の後ろから $C_{in}$ を見たインピーダンスの大きさと位相）、`f3dB`、`midbandDB`、`peak`。

- 基準 `midbandDB` は、結合容量を短絡しトランジスタの容量を無視した実数の中域解析の $A_{vS}$ である。
- $f_L$, $f_H$ は「基準 − 3.01 dB」を最初に上回る点と最後に下回る点で、隣の点との間を $\log f$ で補間する。帯域内の山や谷では動かない。範囲外なら `null` とし、`lowFlag` に `<fStart`、`highFlag` に `>fStop` を入れる。
- 応答が基準より 1 dB 以上高くなる点があれば `peak` にその高さと周波数を入れる。$C_{in}$ を小さくすると、$R_F$–$C_{E2}$–$C_{in}$ の帰還ループの中に低域の極が 2 つ並び、低域にピークが出る。LTspice でも同じ山が出るので、計算上の誤りではない（下表 P, P2）。
- 位相は連続になるようにつなぎ、基準に最も近い点で ±180° の範囲に収める。非反転増幅なので中域ではほぼ 0° になる。

**LTspice との比較**（.ac、全パラメータの .model（IRB, RBM, XTF を含む）、.temp 27、$V_T = 25.8648$ mV、$V_{CC} = 9$ V, $R_F$ 100k, $R_2$ 8.2k, $R_3$ 1.1k, $RV_2$ 500k, $R_{in}$ 1k, $C_{in}$ 1 µF, $C_{E2}$ 20 µF, $C_{out}$ 10 nF）

| 回路 | 基準 | $f_L$ | $f_H$（本ツール / LTspice） | ピーク |
|------|------|------|------|------|
| A: $R_1$ 33k, $RV_1$ 1 Ω | 83.454 dB | 156.55 Hz | 27.77 / 27.78 kHz | なし |
| B: $R_1$ 150k, $RV_1$ 1k | 59.087 dB | 102.55 Hz | 85.88 / 85.92 kHz | なし |
| C: $R_1$ 150k, $R_{BC1}$ 1M, $R_{BC2}$ 220k | 54.060 dB | 25.07 Hz | 267.6 / 267.7 kHz | +2.0 dB（37 Hz） |
| D: C + $C_{BC1}$ 100p, $C_{BC2}$ 220p | 54.060 dB | 25.02 Hz | 3.533 / 3.533 kHz | +2.1 dB（37 Hz） |
| P: A で $C_{in}$ 100n | 83.454 dB | 335.4 Hz | 27.71 / 27.72 kHz | +5.0 dB（537 Hz） |
| P2: B で $RV_1$ 1 Ω, $C_{in}$ 100n | 72.978 dB | 176.3 Hz | 22.77 / 22.78 kHz | +8.7 dB（275 Hz） |

基準と $f_L$ は表示した桁まで LTspice と一致した。10 Hz〜1 MHz の 11 周波数で比べると、6 回路を通じて $|A_{vS}|$ の差は 0.006 dB 以下、位相の差は 0.02° 以下、$|Z_{in}|$ の差は 0.06 % 以下、$f_H$ の差は 0.06 % 以下だった。残る差は、直流で RB, RE, RC を省いたことと、IRB, RBM, XTF を入れていないことによる。

**モデルの範囲**

- 動作点まわりの線形化なので、小信号の周波数特性だけを表す。ファズとして歪ませたときの大振幅の動作（クリップ、バイアスの移動、ゲート状の音切れ）は表さない。
- 飽和したトランジスタがあっても計算はする（$T_R$ の拡散容量も入る）。ただし小振幅でもすぐ線形範囲を外れるので、値は参考にとどまる。
- 中域の実数解析（`ac.Av` など）は容量を入れない。$C_{BC1}$, $C_{BC2}$ が大きいと可聴帯域でも利得が下がる（上表 D）ので、そのときは `acSweep` の値を使う。

## 警告とエラー

各トランジスタの領域は `q1.region`, `q2.region`（`active` / `saturation` / `cutoff`）で返す。次の場合は警告を出す。

- 飽和またはカットオフのトランジスタがある（$V_{CE}$, $V_{BC}$ または $I_C$ を表示し、A_v, Z_in がその動作点での小信号値であることを添える）
- $V_{E2} < 0$ または $V_{C2} < 0$
- $R_1, R_2, R_3$ の電流が逆向き
- 逆計算で根が複数ある、または KCL 残差がやや大きい

入力値の不正（NaN、0 以下、比 $\le 0$ など）と、順方向で実現できない設計はエラーにする。

## パラメータ推定

`js/fit.js`（`FFFit`） は、数点の直流測定 $\{I_B, I_C, V_{BE}, V_{CE}\}$ から Gummel-Poon の IS, BF, NF, ISE, NE, VAF を推定する。画面は `fit.html`。

各測定点で、測定した $v_{be}$ と $v_{bc} = V_{BE} - V_{CE}$ でモデル（`FFEngine.gpDC`）を評価し、残差

$$r = \left[\ln\frac{I_{C,model}}{I_C},\ \ln\frac{I_{B,model}}{I_B}\right]$$

の二乗和を Levenberg-Marquardt 法で最小化する。IS, ISE, BF, VAF は対数、NF（0.9〜2）と NE（1〜4）は範囲付きのロジット変換をかけて探索する。初期値は、最大電流の点から $I_S = I_C e^{-V_{BE}/V_T}$（NF = 1）、BF は測定した $\beta$ の最大値とする。

**推定するパラメータの自動選択**

| 測定点 | 推定する | 固定する |
|------|------|------|
| 1 点 | IS, BF | NF = 1, ISE = 0 |
| $I_C$ が 2 倍以上違う点が 2 水準 | IS, NF, BF, ISE | NE |
| 同 3 水準以上 | 変更なし（NE は自動では推定しない。手動で free にできる） | |
| $I_B$ がほぼ同じ（±10 %）で $V_{CE}$ が 1 V 以上違う 2 点 | + VAF | |

推定しないパラメータは `opts.fixed`、`opts.base`（パース済みのモデル）、既定値（NE = 1.5, VAF = $\infty$）の順に決める。BR, NR, ISC, NC, IKF, IKR, VAR, RB, RE, RC はここでは推定せず、`opts.base` か SPICE の既定値を使う。`opts.free` で推定するパラメータを直接指定できる。$V_{CE} < 0.3$ V の点は飽和の可能性があるので除外し、警告を出す。

結果は推定値、各点のモデル値と $\Delta V_{BE}$（測定 $I_C$ を与えるモデルの $V_{BE}$ と測定値の差）、残差の RMS、`.MODEL FIT NPN(...)` 形式の文字列（有効数字 4 桁）を返す。`FFFit.betaCurve` は指定した $V_{CE}$ での $\beta$–$I_C$ 曲線を返す。

**識別できる範囲**（2SC8888-W から合成した測定値での試験）

- $I_B = 1, 10\ \mu\text{A}$ の 2 点で、NE と BR などを正しく与えれば IS, NF, BF, ISE は正確に戻る。$I_C$ は NE に依存しないので、NE を 1.5 のままにしても IS と NF は正確で、BF が −2.8 %、ISE が数倍ずれる。
- 3 点（1, 10, 100 µA）で NE を free にすると、雑音の無いデータなら NE まで戻る。ただし 100 µA では $I_C \approx 33$ mA で IKF が効くので、IKF を与えないと IS, BF, NE が大きくずれる。
- $V_{CE}$ を変えた 2 点があれば VAF も戻る。
- 測定誤差（$V_{BE}$ ±0.5 mV、電流 ±1 %）を入れると、2 点の推定で IS は ±30 %、BF は ±4 %、NF は ±1.2 % ばらつく（5〜95 パーセンタイル）。IS と NF が相関して動くので、回路の動作点はほとんど変わらない。推定したモデルで逆計算した $I_{C2}$ の誤差は 3 回路で ±0.3 % 以内だった。3 点の推定では、雑音があると NE と ISE は決まらず探索範囲の端に張り付くことがあり、そのときは警告を出す。それでも回路の $I_{C2}$ の誤差は ±0.7 % 以内だった。このため NE は自動選択から外し、既定値（1.5 か base の値）に固定する。
- 1 点だけでは NF と ISE を固定するので、IS と BF は測定点での値に合わせた見かけの値になる。その点の $I_C$, $I_B$ は正確に再現する。

---

## 制限事項

- 直流では RB, RE, RC のオーム抵抗を入れていない。既定モデルでは $R_E I_E \approx 0.2$ mV、飽和時の $R_C I_C \approx 1$ mV 程度の差が LTspice の .op と出る。RB, RE, RC を除いた .model で比べると、直流解は LTspice と µV 以下で一致した。
- RB の電流依存（IRB, RBM）は扱わず、交流でも RB を定数として使う。
- SPICE3 が強い逆バイアス ($v < -3 n V_T$) で使う $c_{be}$ の近似式は使わず、指数式のままにしている。差は $I_S$ の数 % 程度で、無視できる。
- 温度は $V_T$ の入力だけで扱う。IS, BF などの温度依存（EG, XTI, XTB）は計算しないので、結果は TNOM での値になる。$V_T = 25.85$ mV は 300 K（26.85 °C）に当たる。LTspice の既定 27 °C に合わせるなら $V_T = 25.865$ mV とする。
- 順方向計算は目標の $I_C$ を与える設計用で、深い飽和は扱わない。
- 中域の交流解析は結合コンデンサと接合容量を無視する。容量を含む特性は `acSweep` で求める。
